Before you publish: add a real run

Every shared track needs a ghost so players can race the route you built.

  1. Open your track and drive a complete lap/run.
  2. Use Export ghost in the game to copy the ghost code.
  3. Return here, then paste that code into the Ghost code box below.
  4. Name your track, add optional notes or a thumbnail, and publish it to the board.
