Campaign Mode

This mode introduces every major game feature in sequence and stores progress in your profile/account cloud save.

Start Racing Back to menu

Progression roadmap

  1. Complete one lap on the default track.
  2. Play a track from the Track Share Board.
  3. Set a podium time on a shared-track leaderboard.
  4. Publish a track.
  5. Set a #1 leaderboard record.
  6. Install a mod.
  7. Customize your car.
  8. Beat 3 author times.
  9. Beat 3 existing records.
  10. Like tracks.
  11. Continue with advanced repeat goals.
Tip: open Mode Menu (E) in race to view your live campaign stage and progress.
